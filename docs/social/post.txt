给 NekoTrak / VRChat 玩家做了个心率小工具：PulseBridge

盒友们，最近折腾了一个 Windows 心率小工具，叫 PulseBridge，主要想给 NekoTrak 和 VRChat 玩家多一种状态展示玩法。

想法很简单：把穿戴设备或采集程序的心率接到电脑，再放进自己的状态展示里。

目前主要做了这些功能：

♥ 心率看板
实时 BPM、最近 60 秒趋势、会话平均 / 最低 / 最高心率，记录还能导出成 CSV。

↗ 状态输出
可以自定义输出文字，比如「♥ 78 BPM」。软件提供本地文本、JSON 和 HTTP 输出，方便外部状态工具读取。想配合 NekoTrak 使用，可以按其自定义状态里的命令行表达式功能配置读取。

⌁ VRChat Chatbox
提供 OSC 同步选项，在 VRChat 中开启 OSC 后，可以尝试把心率文字显示到 Chatbox。

⌚ 多种接入路线
开放标准心率广播的设备走蓝牙 BLE；已有 Pulsoid 数据可以走云端；自己的采集程序或脚本也可以通过本地 HTTP 推送。

这次 v1.1 还重新做了 LOGO 和界面：深色玫瑰配色，搭配会随当前 BPM 跳动的心形、涟漪、卡片入场和交互过渡。动效可以关闭，断开连接或数据失效后也会停止跳动。

没有设备也能先开「演示模式」，看看界面和输出效果。

接入前说明一下：软件负责接收、展示和输出心率，电脑不会自己测心率。设备能否接入取决于型号、固件与广播能力，部分第三方接入可能需要订阅。NekoTrak 尚未逐版本实测，具体读取方式和展示效果需要按版本配置、确认；VRChat 接收端也需要实际验证。配图中的心率数值均为演示数据。

如果你也在折腾 NekoTrak 状态或者 VRChat Chatbox，欢迎聊聊你想怎么展示自己的心跳，也欢迎带上设备型号交流接入方式。
