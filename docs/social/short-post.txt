给 NekoTrak / VRChat 玩家做了个心率小工具

最近折腾了一个 Windows 小工具：PulseBridge。

把穿戴设备或已有采集程序的心率接到电脑，查看实时 BPM、60 秒趋势和会话统计，再把心率文字交给外部状态工具。

它提供本地文本 / JSON / HTTP 输出，可尝试配合 NekoTrak 的自定义状态命令行功能配置读取；也提供 VRChat Chatbox 的 OSC 同步选项。

接入支持标准 BLE 心率广播、Pulsoid 云端和本地 HTTP。v1.1 新增了 LOGO、深色玫瑰界面和随 BPM 跳动的心形动效，也能先开演示模式看看效果。

设备支持需按型号确认；NekoTrak 未逐版本实测，VRChat 接收端也需实机验证，部分第三方接入可能需要订阅。截图数值均为演示数据。

有同样在折腾状态展示的朋友，欢迎交流。
