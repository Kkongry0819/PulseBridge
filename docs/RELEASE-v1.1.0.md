PulseBridge v1.1.0 · Windows 心率工作台

为 NekoTrak / VRChat 等状态展示场景准备的心率接收与输出工具。

## 下载与使用

下载下面 Assets 中的 **PulseBridge-v1.1.0-windows-x64.zip**，完整解压后双击 `PulseBridge.exe`。请保留同目录 DLL、BLE 辅助程序和其他文件。

- Windows 10 / 11，64 位。
- 自包含桌面运行时，无需单独安装 .NET 10。
- BLE 辅助组件依赖 .NET Framework 4.8；较旧 Windows 10 如未安装，需先安装该组件。
- 首次体验可以选择“演示模式”→“连接设备”。
- `SHA256SUMS.txt` 用于核对发布 ZIP 的完整性。

GitHub 自动附带的“Source code”是源码压缩包；直接使用软件请选择上述 Windows x64 ZIP。

## 主要功能

实时 BPM、60 秒趋势、会话平均 / 最低 / 最高心率、CSV 导出、自定义状态模板、本地文本 / JSON / HTTP 输出，以及 VRChat Chatbox OSC 同步选项。

支持标准 BLE 心率广播、Pulsoid 云端与本地 HTTP 推送三种接入路线。

## 验证与接入条件

构建完成后运行现有的 31 项核心检查；v1.1 界面此前已通过 16 项本地集成检查。

软件负责接收、展示与输出数据，不能通过电脑自行测心率。设备兼容取决于型号、固件与广播能力；部分第三方接入可能需要订阅。NekoTrak 接入需要按版本配置，VRChat 接收端也需实机确认。

详见仓库 README、使用指南以及包内 TEST-REPORT.txt。用于个人状态展示，不用于医疗诊断。
